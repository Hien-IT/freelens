# Contract: Inventory of the Renderer's Node Uses

The disposition of every file of the renderer legacy list
(`scripts/type-check-environments/legacy.jsonc`), and of the files off that list
that bring Node or `electron` into the renderer bundle (research R1, R2). Paths
are relative to `packages/core/src/` unless they start with `freelens/` or
`packages/`.

Dispositions (research R1):

- **S**: the same work with what a browser page and Node both have;
- **I**: a value fetched from main before the frame starts (R4);
- **C**: a channel of [channels.md](./channels.md);
- **M**: the Node part moves under `main/`, or the file splits by process
  behind one injection token;
- **D**: deleted.

Stories: **US1**, values and actions of the machine; **US2**, computations;
**US3**, Node integration off.

A file leaves the renderer legacy list and, if it is there, the Biome exemption
in the change that removes its last Node use (FR-010).
